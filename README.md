# Pascal Mutaka Portfolio

Personal portfolio of Pascal Mutaka, full stack software engineer in Windhoek, Namibia.

**Live site:** https://pascalmtk.github.io/MyPortfolio/

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser to run it locally.

```
index.html          All page content
assets/css          Styles and motion
assets/js           Navigation, motion and the English/French switch (French text is in i18n.js)
assets/img          Portrait and project images
assets/seq          Portrait film frames, scrubbed by scroll (d desktop, m phone)
```

To update a project, edit its `<article class="project">` block in `index.html`. Pushing to `gh-pages` publishes the site.
